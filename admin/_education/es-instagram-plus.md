Group project for the **Software Engineering** course (2020): **Instagram Plus**, a prototype of a social network.

- **Back-end** — Java 8, Spring Boot, Maven and an H2 database, with a JWT-authenticated API.
- **Front-end** — Bootstrap, JavaScript, HTML and CSS.
- A test endpoint fills the database with random accounts, posts, stories, messages, reactions, comments, viewers and followers.

Projeto de grupo da cadeira de **Engenharia de Software** (2020): o **Instagram Plus**, um protótipo de rede social.

- **Back-end** — Java 8, Spring Boot, Maven e base de dados H2, com uma API autenticada por JWT.
- **Front-end** — Bootstrap, JavaScript, HTML e CSS.
- Um endpoint de testes preenche a base de dados com contas, publicações, stories, mensagens, reações, comentários, viewers e seguidores aleatórios.
