Second practical assignment of **Computer Networks Architecture and Protocols** (APRC): **passive network measurements and analysis of NetFlow data**.

The flow records were loaded into an SQLite database and analysed with Python scripts — including IP geolocation and service-name lookups — with the results plotted with Matplotlib.

Segundo trabalho prático de **Arquitetura e Protocolos de Redes de Computadores** (APRC): **medições passivas de rede e análise de dados NetFlow**.

Os registos de fluxos foram carregados para uma base de dados SQLite e analisados com scripts Python — incluindo geolocalização de IPs e nomes de serviços — com os resultados representados em gráficos Matplotlib.
