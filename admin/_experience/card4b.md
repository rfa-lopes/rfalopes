My internship at **Card4B - Systems, S.A.** was focused on a bus kiosk for **Rede Expresso**: I designed and implemented its user interface and integrated a real-time transport API so the kiosk shows accurate trip data.

The result was a working pilot, used internally to validate passenger information systems and payments.
